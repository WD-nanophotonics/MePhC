| workflow | identity lattice | nonidentity lattice |
|---|---|---|
| real space | legacy unit-cell behavior | transformed current basis |
| band | Gamma-K-M-Gamma where eligible | current-BZ generic landmarks |
| Berry | C3/HBZ only when eligible | raw current first-BZ samples |

| plotting | legacy labels where valid | honest generic BZ labels |

name alone.
