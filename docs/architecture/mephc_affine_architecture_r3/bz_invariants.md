# Brillouin-Zone Invariants

For the current reciprocal basis, the BZ boundary is reconstructed as the
Wigner-Seitz cell around reciprocal origin. Validation requires a finite,
open-free polygon with unique vertices, strict counter-clockwise convexity,
positive area equal to the reciprocal-cell area, origin containment, and
consistent reciprocal-vector shell construction.

Nonidentity sampling uses this current BZ. It does not reuse the legacy
triangular K/M/HBZ definitions.
