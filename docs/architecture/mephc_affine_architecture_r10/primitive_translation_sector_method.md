R10 retrieves actual MPB TE eigenfields for q2 A=0, bands 1-12. T(a1) is a one-primitive-cell grid roll along x multiplied by exp(2*pi*i*q1/3); T(a1)^3 therefore carries the supercell Bloch phase. Sector assignment uses the three predeclared roots and residual tolerance 0.02. Gauge, extraction-repeat, and T(a1)^3 controls are recorded for every field. Frequency-only assignment is forbidden.
