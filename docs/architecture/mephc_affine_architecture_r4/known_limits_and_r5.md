# Known Limits and R5

R4 deliberately supports only a globally periodic 2-D square Bravais lattice
with an invertible uniaxial affine transform and a rigid local square hole.

Known limits:
- Berry curvature remains the existing Abelian single-band workflow;
- current-BZ sampling uses deterministic Cartesian points filtered by the
  validated Wigner-Seitz polygon;
- no weighted integration or Chern-number calculation is added;
- no arbitrary affine configuration or pure coordinate rotation is public;
- low-resolution smokes prove execution and propagation, not physical claims;
- existing local scientific records and image archives are not regenerated.

R5 is not authorized. No R5 work was started.
